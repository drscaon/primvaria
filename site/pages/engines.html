Not yet in Isaac Sim. The files follow the standard UsdPhysics schemas, with the PhysX settings and the OmniPhysics deformables in a layer over each file, but no run in Isaac Sim has been done: it needs an NVIDIA RTX GPU. That run is the next milestone.

Newton on CPU. Every preset of the four generators is opened in Newton 1.8.0 with its XPBD solver: mass against the pack, then settling for grains and parts. Where a cell says what Newton does not read, the file follows UsdPhysics and the gap is on Newton's side: it locks a joint axis that has no limit, refuses a joint outside an articulation, and reads the AOUSD proposal's deformable schemas rather than OmniPhysics'.

Fine grains at any scale. Sand and regolith are simulated with lengths and gravity scaled by the same factor, which leaves the motion unchanged and keeps engines away from their absolute tolerances. Each README says how.
