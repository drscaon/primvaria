Three rules, in every generator

Vary

Distributions, not one mesh copied a hundred times: shape, size, tolerance, defects, wear and physics drawn per instance, each with its own seed, and written into the file as ground truth.

Measure

What was generated is measured afterwards: mass, sphericity, drape, stiffness, fit. The numbers ship with the asset, so a training set can be filtered and stratified.

Prove

Every preset passes OpenUSD's validators and physical tests in real engines, read back from the file. What has not been tested is said, in the engine matrix.

The generators

Each is its own package, released on its own schedule. pip install primvaria installs all four and one command line.

Granulaire

granular · grainy

Procedural granular assets: sand, gravel, pebbles, seeds, fruit, pellets and regolith with measured shapes, sizes, masses and four moisture states.

25 presets · 0.07 mm to 5 cm
pip install granulaireDocumentationGitHubPyPI

Maillage

mesh · knit stitch

Procedural cloth assets: towels, napkins, tablecloths, sheets, scarves and flags in real sizes and fabrics, meshed for cloth solvers, with engine-neutral stiffness.

12 presets · 11 fabrics
pip install maillageDocumentationGitHubPyPI

Filaire

wired · wireframe

Procedural cable assets: standard cables with real male and female connectors, from mains, USB and Ethernet to bayonet-locking BNC coax and the servo, battery and balance leads of robots and drones, the receptacles they plug into, and rigid-segment physics from the cable's stiffness.

20 presets · 24 connector families
pip install filaireDocumentationGitHubPyPI

Quincaillerie

hardware · nuts and bolts

Procedural hardware assets: threaded screws, nuts and washers, battery cells and their holders, where tolerances, defects and wear change how parts really behave.

M3–M12 · 41 catalogue assets
pip install quincaillerieDocumentationGitHubPyPI

Tested where it says, and nowhere else

Every preset is checked by OpenUSD's validators, in Blender and in MuJoCo, from the file alone. Isaac Sim has not been run yet. The engine matrix says where each generator stands in each engine, and the OpenUSD contract says what every file holds.

Install and generate

pip install primvaria           # the four generators
pip install "primvaria[all]"    # + renders, MuJoCo checks, MaterialX

Python 3.11+, no GPU needed. One generator only? pip install granulaire, or any of the others.

primvaria list
primvaria granulaire generate --preset beach_sand
primvaria maillage generate --preset tea_towel
primvaria filaire generate --preset usb_c
primvaria quincaillerie generate screw M10 --with nut,washer
