Physics-ready variability for Physical AI, in OpenUSD.

Procedural asset generators for the objects robots struggle with most: grains, cloth, cables and small mechanical parts. No two instances are the same, every value is measured, and every preset is checked in real engines before it ships.

Three rules, in every generator

Vary

Distributions, not one mesh copied a hundred times: shape, size, tolerance, defects, wear and physics drawn per instance, each with its own seed, and written into the file as ground truth.

Measure

What was generated is measured afterwards: mass, sphericity, drape, stiffness, fit. The numbers ship with the asset, so a training set can be filtered and stratified.

Prove

Every preset passes OpenUSD's validators and physical tests in real engines, read back from the file. What has not been tested is said, in the table below.

The generators

Each is its own package, released on its own schedule. pip install primvaria installs all four and one command line.

Granulaire

granular · grainy

Sand, gravel, pebbles, seeds, fruit, pellets and regolith with measured shapes, sizes, masses and four moisture states.

25 presets · 0.07 mm to 5 cm

Maillage

mesh · knit stitch

Towels, napkins, tablecloths, sheets, scarves and flags in real sizes and fabrics, meshed for cloth solvers, with engine-neutral stiffness.

Filaire

wired · wireframe

Standard cables with real male and female connectors, the receptacles they plug into, and rigid-segment physics from the cable's stiffness.

Quincaillerie

Fine grains at any scale. Sand and regolith are simulated with lengths and gravity scaled by the same factor, which leaves the motion unchanged and keeps engines away from their absolute tolerances. Each README says how.

Install and generate

pip install primvaria           # the four generators
pip install "primvaria[all]"    # + renders, MuJoCo checks, MaterialX

Python 3.10+, no GPU needed. One generator only? pip install granulaire, or any of the others.

primvaria list
primvaria granulaire generate --preset beach_sand
primvaria maillage generate --preset tea_towel
primvaria filaire generate --preset usb_c
primvaria quincaillerie generate screw M10 --with nut,washer
